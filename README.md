# Hindsight-Guided Rationale Distillation for Rare Disease Diagnosis

Code, data and results for the paper:

> **Hindsight-Guided Rationale Distillation for Rare Disease Diagnosis**
> ZebraMap · Qwen-2.5-1.5B student ← DeepSeek-R1-Distill-LLaMA-8B teacher

A 1.5B student (Qwen-2.5-1.5B-Instruct) is fine-tuned on chain-of-thought
traces generated by an 8B teacher (DeepSeek-R1-Distill-LLaMA-8B) that saw the
ground-truth label during generation.

| Model    | Training traces              | Role                             |
|----------|------------------------------|----------------------------------|
| Student  | raw teacher traces           | unfiltered ablation              |
| StudentF | regex-filtered traces        | primary model (GT slots removed) |
| Teacher  | DeepSeek-R1-Distill-LLaMA-8B | upper-bound reference            |
| Base     | Qwen-2.5-1.5B-Instruct       | pre-distillation baseline        |

`models/`, `archive/` and the large/intermediate datasets are not
version-controlled. Model weights and the full training corpora are available
on Kaggle:

**Kaggle dataset — final hindsight training data:**
<https://www.kaggle.com/datasets/joetheguide/final-hindsight-training>

[Student training script](https://www.kaggle.com/code/joetheguide/hindsight-raw)
[StudentF training script](https://www.kaggle.com/code/joetheguide/hindsight-clean)

It contains the full cleaned training parquet and the raw contaminated traces.

## Data

The final evaluation set is `data/generated/eval_set_final.parquet`
(2,000 cases, 250 diseases, 8 cases per disease).

The final training corpus is `data/generated/cleaned_with_regex.parquet`
(27,501 samples, "ground truth is X" slots filtered with a regex). The
unfiltered equivalent is `data/generated/uncleaned.parquet`. Both are also
available on the Kaggle link above.

## Pipeline

Run commands from the repository root.

```bash
# 1. Build the base/cleaned datasets from the raw CSV pieces in data/raw
python src/data/dataset_creation.py

# 2. Fine-tune StudentF (reads data/generated/cleaned_with_regex.parquet;
#    writes the LoRA adapter and checkpoints under models/studentF)
python src/training/train_fixed.py

# 3. Evaluate
python src/evaluation/eval.py
python src/evaluation/ft_eval.py

# 4. Statistics
python src/analysis/quantitative_analysis.py
python src/analysis/qualitative_analysis.py
```
